# Shadow Server

Discovery application: `frontend/` contains React and `backend/` contains FastAPI, detection engine, database configuration and tests. The four application APIs, CreditDB MCP and repository hub live in `../repo server/`.

Use the workspace-root `setup.bat`, `start.bat` and `stop.bat` for both servers. See `../README.md` for ports, keys, SDK configuration and validation commands. Existing environment, data and reference records remain under `backend/`.
