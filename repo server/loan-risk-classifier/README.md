# Loan Risk Classifier

Open http://127.0.0.1:5174/#/repos/loan-risk-classifier. The former AI Risk Classifier is now a structured loan form. The repository directory, service name and active API route all use loan-risk-classifier; old browser links redirect to the current route. The app runs on port 8103 and uses local Ollama on port 11434, with qwen2.5:1.5b as the default model.

Enter loan amount, annual interest percentage, term in months, monthly take-home income, living expenses excluding repayments, existing monthly repayments, income source, years in that source, missed payments over the last 12 months, and previous-default status. Savings and collateral are optional; blank means unknown, zero means none. Amounts use the selected INR/USD/EUR/GBP currency. No form values are prefilled with sample borrower data.

For quick demos, click **Load low-risk example** or **Load high-risk example** to fill all fields with fictional values. The form starts blank and loaded values remain editable. Loading an example clears the previous result/error and does not call Ollama; click **Assess loan risk** to request a fresh assessment. Scores are generated by the model rather than preset by these buttons.

POST /api/run accepts {"loan":{...form fields...},"model":"qwen2.5:1.5b"}. The backend validates the numeric inputs and computes a fixed-rate monthly payment (excluding fees), total repayments, repayments/income percentage, monthly surplus after expenses and all repayments, and loan/collateral percentage when collateral is positive. Zero income produces an unavailable ratio, not an error.

Ollama receives the actual entered values and the computed metrics. It generates a 0-100 loan-risk severity score, explanation, adverse factors, mitigants and missing information. The app maps scores to low (0-25), moderate (26-50), high (51-75), severe (76-100). The score is indicative, not a default probability, validated lending rating or approval/rejection decision.

No loan form values or model answers are saved by the application. Actual inference attempts append metadata only (model, app, timestamp, request ID and outcome) to shadow server/backend/logs/ollama_calls.jsonl. GET /api/models lists local models; cloud models and the previously unsuccessful qwen3:0.6b model are excluded. Unit tests mock inference and telemetry writes.

Copy `.env.example` to `.env` in this folder. Set `OLLAMA_MODEL` to an installed local model to change the default, then restart. This server does not read shared .env files or require cloud API keys.
